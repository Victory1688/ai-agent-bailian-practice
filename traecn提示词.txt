# 基于LangChain的RAG实现：文本与结构化数据混合检索

#核心挑战：多模态数据的异构性难题
#在真实业务场景中，信息往往同时存在于非结构化文本（如行业报告、新闻资讯）与结构化数据（如数据库表、业务单据）中，单一的检索方式难以兼顾两类数据的召回效果。
#
#解决方案：双通道查询与结果融合架
#1.文本通道：对文档进行向量化，利用向量检索快速定位语义相似内容，解决“语义理解”需求。
#2.数据通道：识别用户的数值与事实性查询意图，调用SQL引擎或工具链，精准提取结构化数据。
#3. 结果融合：将两通道的结果统一聚合，注入大模型上下文窗口，生成逻辑一致的最终回答。


#核心定义：Retrieval-Augmented Question Answering (检索增强问答) —— 结合外部知识库检索与大模型生成，解决大模型幻觉问题的关键技术。
#技术价值：解决幻觉与提升精度通过引入外部实时的、私有的、专业的知识库，大幅提高AI Agent在企业内部知识库、法律条款解读、医疗问诊等特定垂直领域的回答准确性与专业度，确保回答有据可依。
#

#基于LangChain的RAG实现：多段检索与Top-K融合
#•核心思想：在检索阶段放宽限制，保留多个（Top-K）与查询最相关的段落，而非仅取Top-1。•Top-K 融合：将召回的多个高相关段落整合为一个信息密度更高、维度更丰富的上下文，作为大模型的输入。


#文档预处理与向量化：Embedding模型选择
#核心任务：将非结构化文本（如文档、段落、句子）映射为语义保持的、高维的稠密数值向量，以支撑后续的语义检索与匹配。



# 文本清洗
# 目的：去除非语言符号、冗余字符、HTML标签等干扰数据的“噪声”，净化文本。
# 方法：利用正则表达式 (Regex) 精准匹配并替换或删除无关字符。
# 
# 关键作用：数据质量的第一道防线
# 经过清洗、切分与拼接的标准化文本，将直接作为输入数据，赋能后续的 Embedding (嵌入) 与 Recall (召回) 模块，是确保系统检索准确率的基石。



# 实现步骤
# 
# 01. 向量化 (Embedding)：使用预训练模型（如BERT、OpenAI Embedding）将文本转化为数值化的向量表示。
# 02. 构建索引：将所有知识库文档向量存储于向量数据库(如 FAISS, Milvus)中，并构建高效索引以加速检索。
# 03. 相似度检索：计算查询向量与库中向量的余弦相似度，进行Top-K排序，返回最相关的文档。



#1. `AgentHub` 消息总线：支持单播 send + 广播 broadcast，作为多 Agent 通信中心；
#2. 任务流程：
#   - AgentA：拆分任务，广播给 AgentB、AgentC
#   - AgentB / AgentC：收到任务，随机选择部分子任务执行，把结果发给 AgentD
#   - AgentD：收集 B、C 的消息，汇总全部结果生成结论
#3. LangGraph 图结构：agentA 执行后**并行触发 agentB 和 agentC**，两个节点都完成后，才进入 agentD 汇总。


#- 自定义`MCPInterface`用来**跨节点持久保存上下文**，和 LangGraph 内置 State 并行，演示外部上下文存储方案；
#- 流程：`preprocess（保存query）` → `retrieve（模拟检索，保存检索结果）` → `conclude（读取MCP上下文，生成总结）`；
#- 最后打印`mcp.context_store`，查看全部阶段保存的上下文。

# 整个科研助手链路一共**5 个节点串行执行**：
# `预处理(提取关键词)` → `文献检索` → `文献去重筛选` → `生成摘要` → `汇总结论`
# 所有节点共享同一个`State`状态，每个节点输出的字段都会保留在上下文中。


工具链动态规划逻辑：实现任务的自动分解与执行


动态规划逻辑是智能体的核心能力之一。它让智能体不再被动执行单一指令，而是能够理解任务的上下文和目标，动态判断调用的工具类型与顺序，从而将复杂的任务自动拆解为可执行的步骤序列，完成端到端的自主规划与执行。


Tools & Agent 集成
External Integration  赋予模型行动能力，连接外部工具与知识库，让AI能够自主决策并与外部世界交互。


Memory 记忆管理
Memory Management 赋予模型长期记忆，保留对话历史与上下文信息，实现具备连贯性的智能对话体验。


沙箱 (Sandbox)
一种关键的安全机制，通过创建独立的隔离执行环境，严格限制外部工具的运行权限和资源使用范围，从根本上防止恶意操作或程序故障对主系统造成破坏或数据泄露。


多工具调用顺序管理：实现复杂任务流
核心概念：许多复杂任务需要多个工具按特定顺序协同工作。显式地管理调用顺序，可以消除执行歧义，显著提高系统的稳定性和结果的可控性


自定义提示词驱动智能体：定制Agent的“灵魂”


核心概念：提示词即“指令集” 在 LangChain 框架中，Agent 的行为逻辑完全依赖大模型的推理能力，而提示词就是引导推理方向的“核心指令集”，是实现 Agent 能力定制化的最关键手段。
