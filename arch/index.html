大模型 Agent 五模块架构

接口 / 感知 / 认知 / 执行 / 记忆 五大模块 + 横切支撑层。源文件：llm-agent-architecture.svg

读图要点

  • 接口模块是边界层，把外部请求/事件翻译成 Agent 内部统一形态，并负责输出渲染；它常被并入感知与执行，是否独立计为第 5 个模块取决于划分粒度。
  • 认知模块是决策核心（由 LLM 驱动），实际包含三件事：规划（任务分解）、推理（含工具选择）、反思（自我纠错）；生产系统还会加一层模型路由/降级。
  • 记忆模块是横切能力：认知模块读写它（检索 + 回写），执行模块把任务轨迹写入它；工程上分短期（上下文窗口）/ 长期（向量库 RAG）/ 情景（轨迹）/ 语义（画像规则）四层。
  • 左侧虚线是 ReAct 循环：执行结果作为 Observation 回灌到感知与认知，形成 思考 → 行动 → 观察 的迭代。
  • 支撑层不单列流程，但必须一开始就设计：编排调度、安全与对齐（护栏）、可观测与评估、成本与限流。
