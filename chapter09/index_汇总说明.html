一、char09 的核心命题

从单 Agent 到多 Agent——第一次把"多个 Agent 怎么一起干活"当作独立工程对象来设计。

char01-08 都在"造一个 Agent"——给它加工具、加记忆、加状态、加降级。char09 是全书第一次把多个 Agent 摆在一起，问四个全新的工程问题：

  1. 协作模式：两个 Agent 之间的数据怎么传？（直接传递 / 黑板共享）
  2. 调度策略：有多个可选 Agent/任务时怎么选？（轮询/加权 / DAG 依赖解锁）
  3. 并发管理：多 Agent 同时跑时怎么防串台/写坏？（并行 + 隔离 + 同步）
  4. 通信协议：Agent 之间发消息，消息长什么样？（结构化元信息）

二、四层架构速览

L4 协作模式层（01-02）

怎么一起干活：01 主控写死调度链（直接传递）→ 02 黑板共享解耦（SharedState）。两种数据交互范式的对照。

L3 调度策略层（03-04）

怎么选谁先干：03 无依赖选择（轮询取模 / 重池加权）→ 04 有依赖 DAG（heapq 优先级堆 + depends 解锁）。

L2 并发管理层（05-07）

怎么同时干不坏：05 并行执行（Thread + join）→ 06 上下文隔离（task_id 命名空间）→ 07 状态同步锁（Lock 临界区）。并发三部曲。

L1 协议格式层（08）

干的过程中怎么发消息：08 篇是纯注释 JSON 结构示例——id / from / to / type / priority / context_ref / payload / auth。

四、三种协作模式对照

模式一：直接传递（01）

主控.run():
  news → analysis → report
  # 上游输出 = 下游输入
  # 顺序写死，耦合度高

风险上游低质量 → 下游幻觉放大

模式二：黑板共享（02）

Agent_A → SharedState → Agent_B
  # 写入者和读取者解耦
  # 黑板成中间枢纽

优点灵活性高，增减 Agent 不影响其他

模式三：并行+隔离+同步（05-07）

Thread_1 ──┐
Thread_2 ──┼→ SharedLog + Lock
Thread_3 ──┘
  # 各线程独立 LLM 调用
  # ContextScope 分桶防串台

组合并行加速 + 隔离安全 + 锁保护共享

五、三条不变式（新人最先认出的模式）

不变式 1：统一改写范式

问题教材写法改写为
虚构 importfrom qwen_agent.agent import Agentdashscope.Generation.call
虚构 Tool 继承class XxxAgent(Tool): super().__init__(...)纯类 + self.name/description
虚构 Agent.chatagent = Agent(); agent.chat(messages=[msg])dashscope.Generation.call(model="qwen-plus", messages=[...])

不变式 2：调度的本质 = 决策函数

03 轮询：  counter % N → 选中 agent_i
03 加权：  random.choice(重池) → 等概率
04 DAG：   depends 全空或已执行 → 入堆 → 堆顶先出

char05 LangGraph 条件边是这个家族的框架化升级版——理解了 03/04 的决策函数，LangGraph 不再是黑盒。

不变式 3：并发安全三原则（优先级从高到低）

  1. 能隔离就不共享（06 ContextScope：每个任务独立命名空间，数据结构上不可能串）
  2. 能免锁工具就不手写锁（queue.Queue：标准库线程安全容器）
  3. 必须共享时才用 Lock（05/07：显式互斥，牺牲并发性换正确性）

六、实测四笔学费

学费 1 幻觉放大链（01/02）

上游只喂硬编码事实 → 下游 LLM 自行编造 PMI 51.2 / CPI 0.4% 等精确数字 → 报告读起来极其可信但全是幻觉。幻觉治理要在源头加校验 + LLM 整合加约束。

学费 2 权重是概率不是配额（03）

权重 1:1:3 的 3 次实测：agent_1 占 67%（理论 20%）。小样本不能判断权重效果，100 次才收敛。

学费 3 锁内耗时是反模式（07）

sleep(0.5) 放临界区让三次写入至少 1.5s 串行。生产级做法：锁内只塞队列（微秒），锁外专门线程消费。生产者-消费者模式。

学费 4 文件名拼写错误（08）

08 篇文件名 08_agnet之间交互元信息例子.py——"agnet" 是 "agent" 的拼写错误。内容是纯注释 JSON 示例，无可运行代码。

关键认识：生产框架只是把本篇的手写模式做成了声明式 API——理解了本篇，任何多 Agent 框架都不是黑盒。

九、学习路径 + 配套资源

6 步学习路径

  1. 跑 01+02 → 对比两种协作模式（自测：说清直接传递 vs 黑板）
  2. 跑 03+04 → 调度的本质是决策函数（自测：手写 DAG 调度器）
  3. 跑 05 → 感受并行加速（自测：实测串行 vs 并行耗时）
  4. 跑 06 → 理解隔离为什么重要（自测：去掉隔离看串台）
  5. 跑 07 → 理解锁的语义与代价（自测：去掉锁看打印交错）
  6. 综合 → 05+06+07 组合成完整并发系统，用 04 DAG 做调度
